# 墨画 · 国风设计

国风在线设计工具（Figma 风格轻量版）。纯前端，无后端。

## 功能

- 画布编辑：文字、矩形、圆形、线条、图片上传；选中/拖拽/缩放/旋转；图层上移下移；删除；撤销重做；缩放
- 属性面板：颜色、字号、透明度；文字双击编辑
- 国风元素：12 种自绘 SVG 装饰、32 色中国传统色、印章生成器（2–4 字）
- 模板：春节海报、国风名片、朋友圈封面、中秋贺卡、保险节日问候、保险知识科普
- 画布预设：海报 1080×1920、方图 1080×1080、名片 1050×600
- 导出 PNG；localStorage 保存/读取；JSON 导入导出

## 开发

```bash
npm install
npm run dev
npm run build
```

GitHub Pages 部署路径为 `/guofeng-design/`（见 `vite.config.js` 的 `base`）。

## 字体

使用系统中文字体栈（楷体/宋体/雅黑等），不依赖 Google Fonts。
